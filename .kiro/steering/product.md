# Product Overview

This is a mobile education management application built with React Native and Expo. The app facilitates communication and tracking between students, parents, and teachers in an educational setting.

## Core Features

- User authentication with Google Sign-In integration
- Real-time notifications and messaging via SSE and WebSocket
- Location tracking and history for student safety
- Course and attendance management
- Parent-child account linking
- Chat and messaging system
- Student analytics and performance tracking
- Onboarding flow for new users

## User Roles

The application supports multiple user types with role-specific features:
- Students
- Parents (linked to student accounts)
- Teachers (with control panel and analytics)

## Design Philosophy

The app emphasizes a premium, polished user experience with:
- Rich animations using react-native-reanimated
- Comprehensive dark mode support
- CSK Green (#097D46) as the primary brand color
- Rubik font family throughout
- Material Design principles for dark mode
